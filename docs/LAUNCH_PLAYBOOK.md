# Launch Playbook

Use this checklist to maximize adoption after publishing.

## Week 1
- Post launch thread on X/LinkedIn with a reproducibility failure story and fix.
- Share demo in:
  - r/LocalLLaMA
  - r/programming
  - Hacker News ("Show HN")
- Publish a short article: "Why AI code that works is not enough without replay proof."

## Week 2
- Submit to curated lists:
  - awesome-ai-tools
  - awesome-devtools
  - awesome-python
- Open 3 integration examples in separate repos (Node, Python, mixed mono-repo).

## Week 3
- Add benchmark comparisons vs baseline workflow (time to detect flaky behavior).
- Collect first 10 user reports and prioritize roadmap updates.

## Content Assets
- 30-second terminal demo GIF.
- Architecture diagram of baseline/contract/replay/report.
- "Top 5 reproducibility bugs detected by ReproGuard" post.

## Distribution Rules
- Always include one reproducible command.
- Always include one concrete artifact screenshot.
- Always link to release notes and quick-start.
